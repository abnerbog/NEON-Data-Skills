# Introduction  

This collection brings together hydrology-themed tutorials from the NEON Data Skills repository (https://github.com/NEONScience/NEON-Data-Skills). The tutorials are developed and maintained by the NEON data skills team and cover working with NEON aquatic and hydrologic datasets. Each tutorial includes step-by-step code examples with explanations, and most are available in both Python and R.


# How to use these materials

Tutorials in this collection can be used independently. Each one is self-contained and includes the code and context needed to work through the example on its own. Python users can follow along using the Jupyter notebook versions of each tutorial. Where available, R users can access the same content through the companion R Markdown files. If you are new to NEON hydrology data, it may help to review the collection of [NEON Hydrologic Data Products](https://hydroshare.org/resource/53718072f33646fa920f1b72d7b403eb/) HydroShare collection before diving in.
